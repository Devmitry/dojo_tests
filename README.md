# Dojo Tests

Тестовое задание, состоящее из двух адаптивных веб-страниц:

- `test-1` — лендинг «Додзё Медиа» с адаптивной вёрсткой, мобильным меню и оптимизированными изображениями.
- `test-2` — страница услуг стоматологии с интерактивной каруселью, адаптивным блоком консультации, валидацией формы и возможностью подключения внешнего API через `site-config.js`.

Проект выполнен на HTML, CSS и JavaScript без фреймворков.

При выполнении тестового задания использовалась модель **GPT-5.6 Sol**.

Общее время работы — примерно **8 часов** в течение трёх дней с перерывами:

- первая часть — около 2 часов;
- вторая часть — около 6 часов.

## Запуск

Откройте `index.html` нужной части в браузере или запустите локальный статический сервер из корня проекта.
