# Dojo Tests

Тестовое задание, состоящее из двух адаптивных веб-страниц:

1) `test-1` - лендинг «Додзё Медиа».
2) `test-2` - страница услуг стоматологии.

Проект выполнен на HTML, CSS и JavaScript без фреймворков.

При выполнении тестового задания использовалась модель **GPT-5.6 Sol**.

Общее время работы - примерно **8 часов** в течение трех дней с перерывами:

1) первая часть - около 2 часов;
2) вторая часть - около 6 часов.
